## 📄 Введение

Bjorn — мощный инструмент для комплексного сканирования сети, оценки уязвимостей и эксфильтрации данных. Модульная архитектура и широкие возможности настройки позволяют выполнять гибкие и целенаправленные операции. Комбинируя различные действия и интеллектуально управляя ими, Bjorn предоставляет ценную информацию о сетевой безопасности и помогает выявлять и устранять потенциальные риски.

e-Paper HAT дисплей и веб-интерфейс обеспечивают удобный мониторинг и взаимодействие с Bjorn в режиме реального времени. Благодаря расширяемой архитектуре и настраиваемым действиям, Bjorn можно адаптировать для широкого спектра задач тестирования безопасности и мониторинга.

## 🌟 Возможности

- **Сканирование сети**: Обнаружение активных хостов и открытых портов; сканирование **нескольких подсетей** (`custom_subnets`).
- **Оценка уязвимостей**: Сканирование уязвимостей с использованием Nmap и других инструментов.
- **Атаки на системы**: Брутфорс-атаки на различные сервисы (FTP, SSH, SMB, RDP, Telnet, SQL) с общим трекером прогресса (% в вебе).
- **Кража файлов**: Извлечение данных из уязвимых сервисов.
- **Пользовательский интерфейс**: отображение на e-Paper HAT **и/или веб-интерфейс** — **headless-режим** (`epd_type:"none"`, без HAT) и **preview-эмулятор** (`epd_type:"preview"`).
- **Веб-интерфейс**: страница логина + сессионные cookie, мониторинг, управление конфигурацией и системой.
- **Стабильность**: singleton EPDManager с защитой SPI и авто-recovery, мониторинг здоровья (потоки/RSS/FD), блокировка запуска двух экземпляров.
- **Поддержка ОС**: Raspberry Pi OS Bookworm (12) и Trixie (13).

## 📌 Предварительные требования

### 📋 Для RPI zero W (32-бит)

- Установленная Raspberry Pi OS (Legacy, 32-bit).
    - Стабильная:
      - Система: 32-бит
      - Версия ядра: 6.12
      - Версия Debian: 12 (bookworm) '2026-04-13-raspios-bookworm-armhf-lite'
- Имя пользователя и hostname установлены в `bjorn`.
- e-Paper HAT 2.13 дюйма подключён к GPIO-пинам.

### 📋 Для RPI zero W2 (64-бит)

![image](https://github.com/user-attachments/assets/e8d276be-4cb2-47a4-a74a-5b5b6704d22f5)

Проект не разрабатывался специально для Raspberry Pi Zero W2 64-бит, но несколько отзывов подтвердили, что установка работает корректно.

- Установленная Raspberry Pi OS (Legacy, 64-bit).
    - Стабильная:
      - Система: 64-бит
      - Версия ядра: 6.12
      - Версия Debian: 12 (bookworm) '2026-04-13-raspios-bookworm-arm64-lite'
- Имя пользователя и hostname установлены в `bjorn`.
- e-Paper HAT 2.13 дюйма подключён к GPIO-пинам.

### 📋 Для RPi 5 (64-бит)

- Установленная Raspberry Pi OS (Legacy, 64-bit).
    - Система: 64-bit (ARM64/aarch64; 32-bit не поддерживается на BCM2712)
    - Версия ядра: 6.12
    - Версия Debian: 12 (bookworm) '2026-04-13-raspios-bookworm-arm64-lite'
- Имя пользователя и hostname установлены в `bjorn`.
- e-Paper HAT 2.13 дюйма подключён к GPIO-пинам.
- **Минимальная версия Bjorn**: v1.5.0+ (мульти-источник platform detection, headless, login, preview).


На данный момент протестированы и поддерживаются экраны v2 и v4.
Надеемся, что V1 и V3 также будут работать корректно.

### 🔧 Совместимость с оборудованием

| Плата | Статус | Минимальная версия Bjorn |
|---|---|---|
| RPi Zero W (BCM2835) | ✅ | v1.0.0+ |
| RPi Zero W2 (BCM2837) | ✅ | v1.0.0+ |
| RPi 5 (BCM2712) | ✅ | **v1.5.0+** |

### ✅ Debian Trixie (13)

Начиная с **v1.4.0** Bjorn поддерживает и Bookworm (12), и Trixie (13).

Можно использовать как актуальную RPi OS (Trixie), так и Legacy (Bookworm):
[raspberrypi.com/software/operating-systems](https://www.raspberrypi.com/software/operating-systems/).

### 🔨 Установка

Самый быстрый способ установить Bjorn — использовать скрипт автоматической установки:

```bash
# Скачать и запустить установщик
wget -O install_bjorn.sh https://chumikovsec.ru/install
sudo chmod +x install_bjorn.sh && sudo ./install_bjorn.sh
# Выберите вариант 1 для автоматической установки. Это может занять некоторое время, так как будет установлено множество пакетов и модулей. Необходимо выполнить перезагрузку по завершении.
```

## 💡 Пример использования

Демонстрация того, как Bjorn автономно охотится по вашей сети как викинг-налётчик (фиктивная демонстрация для иллюстрации):

```bash
# Фаза разведки
[NetworkScanner] Обнаружение активных хостов...
[+] Найден хост: 192.168.1.100
    ├── Порты: 22,80,445,3306
    └── MAC: 00:11:22:33:44:55

# Последовательность атак
[NmapVulnScanner] Обнаружены уязвимости на 192.168.1.100
    ├── MySQL 5.5 < 5.7 - Перечисление пользователей
    └── SMB - Кандидат на EternalBlue

[SSHBruteforce] Подбор учётных данных...
[+] Успех! user:password123
[StealFilesSSH] Извлечение конфиденциальных данных...

# Автоматическая эксфильтрация данных
[SQLBruteforce] База данных доступна!
[StealDataSQL] Дамп таблиц...
[SMBBruteforce] Шара доступна
[+] Найдены конфигурационные файлы, учётные данные, резервные копии...
```

Это лишь демонстрационный вывод — реальные результаты зависят от вашей сети и конфигурации целей.

Все обнаруженные данные автоматически организуются в каталоге data/output/, отображаясь как на e-Paper дисплее (в виде индикаторов), так и в веб-интерфейсе.
Bjorn работает неустанно, расширяя свою базу знаний о сети и становясь сильнее с каждым открытием.

Не нужно постоянного мониторинга — просто разверните и позвольте Bjorn делать то, что он умеет лучше всего: охотиться на уязвимости.
